# Attribution

The continuous-action benchmark in `simulations/core/kz2018aistats/` implements
the method of Nathan Kallus and Angela Zhou, “Policy Evaluation and Optimization
with Continuous Treatments,” AISTATS 2018. The implementation is retained from
the manuscript's existing code, with unused utility functions removed.

`realdata/core/neuralnet/oadam.py` retains its original attribution to George
Paraskevopoulos's `optimistic-adam` implementation and its MIT-license header.
The optimizer is based on “Training GANs with Optimism.”

This folder retains the notices present in the supplied source; it does not
assign a new license to the manuscript code or the proprietary auto-loan data.
