# PRINT: numerical reproduction

This folder can be copied out of the manuscript repository. It contains the
code for the simulation study and the auto-loan application, the simulation
results used to draw Figure 1, and the fitted models needed by the real-data
workflow. The auto-loan dataset is not included; see
[Auto-loan data](#auto-loan-data) for how to obtain it.

| Directory | Results | Inputs |
| --- | --- | --- |
| [`simulations/`](simulations/README.md) | Figure 1: regret versus sample size | Synthetic data generated by the code; reference results included |
| [`realdata/`](realdata/README.md) | Table 1 and Figures 2–3 | Fitted PRINT, demand, and KZ18 models included; auto-loan CSV obtained separately |

There are no seed-search scripts, hyperparameter-search launchers, or search
histories. Simulation seeds index the 50 Monte Carlo replications, all of which
are retained. Optional PRINT retraining uses one fixed seed, 1; the regression
benchmark uses one fixed seed, 0.

## Installation

Use Python 3.12. From this folder:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

The direct dependencies are pinned to the versions used for the local release
checks, recorded in `tested_environment.json`. Simulations and saved PRINT
model evaluation run on a CPU. A CUDA GPU is recommended for neural-network
training. Retraining can produce different numerical values across hardware
and library versions.

## Figure 1

Redraw the figure from the included reference simulation results:

```bash
python simulations/bin/make_fig1.py
```

The output is `simulations/results/figs_out/sim_regret_vs_n.{png,eps}`. The
reference CSVs are the ones behind the manuscript's current Figure 1. Lines
show median regret; shaded regions show the interquartile range.

To rerun all four scenarios and all three methods, with 50 replications per
sample size:

```bash
RESULTS_DIR="$PWD/simulations/fresh_results" bash simulations/bin/run_simulations.sh
```

For a smaller check:

```bash
NS=1000 N_RUNS=1 RESULTS_DIR="$PWD/simulations/check_results" \
  bash simulations/bin/run_simulations.sh
```

See the [simulation instructions](simulations/README.md) for sample sizes,
estimator settings, the KZ18 sample cap, and the distinction between the saved
figure values and deterministic fresh reruns.

## Table 1 and Figures 2–3

### Auto-loan data

The original CPRM-12-001, *On-Line Auto Lending*, dataset referenced in the
manuscript is not included in this repository. It can be obtained from the
Center for Pricing and Revenue Management at Columbia Business School by
emailing [cprm@gsb.columbia.edu](mailto:cprm@gsb.columbia.edu).

Put the CSV file, with its original filename and row order, in the `AutoLoan`
folder:

```text
realdata/data/AutoLoan/CPRM_AutoLOan_OnlineAutoLoanData.csv
```

The saved models depend on the original row order, so do not sort or filter
the file. The data dictionary and dataset description PDFs are already in the
same folder.

### Running the workflow

With the CSV in place, run:

```bash
bash realdata/run.sh
```

The scripts read the CSV from the `AutoLoan` folder above by default. To use a
copy stored elsewhere, set `DATA_DIR=/path/to/data`, where that directory
contains `AutoLoan/` with the same CSV filename and original row order.

This uses the supplied PRINT, demand, and KZ18 models, fits the regression
benchmark at seed 0, and writes the table and figures under `realdata/out/`.
The [real-data instructions](realdata/README.md) also describe evaluating just
the saved PRINT model's partial-dependence curves and optional single-seed
PRINT retraining.

## Included material

The reference simulation summaries and fitted real-data models are bundled. The
auto-loan CSV (see [Auto-loan data](#auto-loan-data)), saved per-record loan
predictions, cluster submission scripts, and historical search outputs are
excluded. Output paths can be set
without changing the source. The original manuscript code and PDFs remain
separate from this folder.

See [THIRD_PARTY.md](THIRD_PARTY.md) for retained code attributions.

## Validation performed

The release was copied to a separate directory and its entry points and model
loads were checked there. The reference Figure 1 redraw matches the manuscript
PNG pixel for pixel. A small simulation run passed all four scenarios and all
three methods, and repeated runs reproduced their CSV values. Real-data checks
covered model inference, Figure 3 generation on synthetic inputs, and a small
PRINT fit followed by checkpoint resume. The data loader was checked on all
208,085 records using the default data path. The full 50-replication experiment
and full real-data fitting workflow were not rerun during packaging.
